# TD — TASTE DISCOVERY

음식과 주류 페어링 미식 커뮤니티의 정적 웹앱 시제품입니다.

## 현재 구현
- 반응형 첫 화면과 4개 카테고리 (와인 페어링, 전통주 페어링, 싱글몰트 페어링, 모임 후기)
- 모임 일정 및 후기 브라우저 로컬 임시 저장
- AI 질문 복사 및 ChatGPT 링크 (실제 AI API 연동 아님)
- PWA 설정, 임시 아이콘, 기본 오프라인 캐시

## 제한과 보안
로그인, 운영자 승인, 회원 간 데이터 공유, 서버 DB, 실제 AI API 호출은 아직 구현되지 않았습니다. 브라우저에 저장한 데이터는 기기를 바꾸면 공유되지 않으며 브라우저 데이터를 삭제하면 사라집니다. 민감한 개인정보를 입력하지 마세요. API 비밀키는 절대로 index.html 등 공개 파일에 넣지 마세요.

## 배포
GitHub Settings → Pages → Deploy from a branch → main / (root).

3. 모임 공개를 위한 운영자 승인 및 권한 검사
4. AI 서버 프록시와 비용·사용량 제한
5. 공식 로고 이미지 교체 및 모바일 기기 테스트
